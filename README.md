# avaliacao-de-metricas
# 📊 Avaliação de Métricas — Projeto de Deep Learning

Este repositório contém a implementação de um projeto desenvolvido durante o **Bootcamp de Deep Learning da DIO**, cujo objetivo foi **avaliar métricas de desempenho de um modelo de Rede Neural Artificial** aplicado a um conjunto de dados real.

O foco principal foi compreender o impacto das métricas na análise dos resultados, treinar o modelo corretamente e interpretar seus outputs.

---

## 🧠 Objetivo do Projeto

O desafio consistiu em:

* Criar uma Rede Neural Artificial totalmente conectada
* Treinar o modelo sobre um dataset supervisionado
* Avaliar as métricas fundamentais de desempenho
* Comparar e interpretar os resultados
* Entender como a escolha das métricas influencia a performance do modelo

---

## 🛠️ Tecnologias Utilizadas

As seguintes tecnologias e bibliotecas foram utilizadas para construção, treino e avaliação do modelo:

### ✅ **Python**

Linguagem principal usada para processamento, modelagem e análise.

### ✅ **TensorFlow / Keras**

Utilizado para:

* Construção da Rede Neural Artificial
* Definição das camadas densas
* Treinamento supervisionado
* Cálculo de métricas automáticas

### ✅ **NumPy & Pandas**

Usadas para:

* Manipulação do dataset
* Limpeza e preparação dos dados
* Criação de estruturas organizadas

### ✅ **Matplotlib / Seaborn** (caso tenha usado)

Para:

* Plotar gráficos
* Visualizar comparações de métricas
* Acompanhar evolução do treinamento

---

## 📈 O que foi aprendido

Durante o desenvolvimento deste projeto, foram explorados e compreendidos conceitos essenciais como:

✅ Diferença entre métricas de classificação e regressão
✅ Quando usar *accuracy*, *precision*, *recall* e *F1-score*
✅ Importância da matriz de confusão
✅ Como interpretar perdas (*loss*) e erros do modelo
✅ Treinamento prático de uma rede totalmente conectada
✅ Impacto da normalização e preparação dos dados
✅ Comparação entre valores previstos e valores reais

---

## ✅ Resultado do Projeto

Ao final, foi possível:

* Treinar uma Rede Neural Artificial funcional
* Avaliar corretamente métricas de desempenho
* Interpretar graficamente os erros do modelo
* Identificar pontos de melhoria no dataset e no modelo
* Entender como pequenos ajustes podem alterar drasticamente a performance

O projeto cumpriu o objetivo de consolidar conhecimentos fundamentais em **deep learning aplicado**, métricas e boas práticas de avaliação.


---

## 🚀 Conclusão

Este projeto foi essencial para reforçar conhecimentos de Machine Learning e Deep Learning, com foco especial em **como avaliar corretamente um modelo treinado**.
A prática com métricas reais e dados reais permitiu compreender não só o treinamento da RNA, mas principalmente a **qualidade das previsões**.
